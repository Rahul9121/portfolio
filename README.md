# Rahul Ega — Data Analyst Portfolio

Personal portfolio website of **Rahul Ega**, a Senior Data Analyst with 5+ years of experience across **healthcare, banking, and fintech**, specializing in SQL, Python, BI dashboards, predictive modeling, and data storytelling.

🌐 **Live site:** [rahul9121.github.io/portfolio](https://rahul9121.github.io/portfolio/)

---

## ✨ Highlights

- Single-page, fully responsive portfolio built with vanilla **HTML, CSS, and JavaScript** — no framework dependencies.
- Modern dark/light theme with animated particle background, glassmorphism cards, parallax photo frames, and tilt/reveal interactions.
- SEO-optimized: rich meta tags, Open Graph + Twitter cards, JSON-LD structured data (Person, WebSite, ItemList, FAQPage), `sitemap.xml`, `robots.txt`, and `llms.txt` for AI crawlers.
- Sections covering **About, Skills, Projects, Experience, Education, FAQ, and Contact**.

---

## 🛠️ Tech Stack

| Layer | Tools |
|------|-------|
| Markup | HTML5, semantic landmarks, schema.org JSON-LD |
| Styling | CSS3 (custom properties, flex/grid, animations), Google Fonts (Inter, Space Grotesk), Font Awesome 6 |
| Interactivity | Vanilla JavaScript (canvas particles, IntersectionObserver reveals, theme toggle, tilt/parallax) |
| Hosting | GitHub Pages |

## 🚀 Run Locally

Clone the repo and open `index.html` directly in any modern browser, or serve it with a tiny local server:

```bash
git clone https://github.com/Rahul9121/portfolio.git
cd portfolio

# Option 1: Python
python -m http.server 8000

# Option 2: Node
npx serve .
```

Then visit <http://localhost:8000>.
